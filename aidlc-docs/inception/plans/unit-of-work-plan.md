## Question 8 — 디렉터리 구조 (Code Organization)
소스 코드를 어떤 구조로 배치할까요?

A) **기능 우선 (feature-first)** — `src/modules/{auth,titles,pipeline,...}/` 아래에 각 기능의 서비스·리포지토리·스키마·UI를 모아 두고, 공유 코드는 `src/platform/`과 `src/domain/`에 둔다 (**권장** — 유닛 경계가 디렉터리로 드러나므로 유닛별 작업 범위가 물리적으로 분리됨)

```
src/
  app/            Next.js 라우트 및 API 경계
  modules/        기능별 (auth · titles · pipeline · evaluation · deals · dashboard · dataio)
  platform/       X1~X6 횡단 관심사
  domain/         D1~D6 순수 함수 (import 금지 구역)
  db/             Prisma 스키마 · 마이그레이션 · 시드
```

B) **계층 우선 (layer-first)** — `src/services/`, `src/repositories/`, `src/schemas/` 로 나누고 그 안에 전 기능을 담는다. 계층 구분은 명확하나 하나의 기능이 여러 폴더에 흩어진다
