## 4. 질문과 답변 (2026-07-27 확정)

**사용자 응답: "권장안대로"** — Q-FD-1~4 전부 권장안(A) 채택.

| 질문 | 답변 | 반영 |
|---|---|---|
| Q-FD-1 철회 권한 | **A** 작성자 본인 + Analyst + Executive | BR-U6-009, `signal:retract` |
| Q-FD-2 키워드 | **A** 자유 입력 (태그) | `Signal.keywords`, 표기 분화는 감수 |
| Q-FD-3 유사작 등록 역할 | **A** Scout + Analyst | `comparable:write` |
| Q-FD-4 근거 탭 필터 | **A** 종류(kind) 필터만 | 근거 탭 설계 |

> 아래는 원 질문과 권장 근거를 기록으로 남긴 것입니다.

### Q-FD-1. 관측 철회 권한에 **작성자 본인**을 포함할까요?

요구사항의 `signal:retract`는 현재 Analyst·Executive입니다. Scout가 자기가 방금 잘못
기록한 관측을 스스로 못 지우면, 남에게 부탁해야 합니다.

- A) **작성자 본인 + Analyst + Executive** ← 권장
- B) Analyst + Executive만 (요구사항 원안 유지)
- C) 작성자 본인만 (관리자도 못 건드림)

> **권장 근거**: 철회는 삭제가 아니라 무효화 표시이고 원본이 남으므로(BR-U6-002),
> 본인에게 열어도 은폐 수단이 되지 않습니다. Q-U6-1에서 이미 행 단위 권한을 도입하기로
> 했으므로 추가 비용도 없습니다.

[Answer]: A (권장안)

### Q-FD-2. 리뷰 **키워드**를 자유 입력으로 할까요, 고정 목록으로 할까요?

- A) **자유 입력 (태그)** ← 권장
- B) 고정 목록에서 선택
- C) 자유 입력 + 기존 키워드 자동완성 제안

> **권장 근거**: 해외 리뷰의 키워드는 작품마다 새로 생깁니다. 고정 목록은 처음부터
> 맞을 수 없고, 목록에 없는 말을 못 적으면 관측이 왜곡됩니다.
> **다만 대가가 있습니다** — `느와르`/`누아르`처럼 표기가 갈라집니다. C안이 이를
> 줄이지만 구현 비용이 붙습니다. 이 규모(10명)에서는 A로 충분하다고 봅니다.

[Answer]: A (권장안)

### Q-FD-3. **유사작을 등록할 수 있는 역할**은?

요구사항의 `comparable:write`는 현재 Analyst만입니다.

- A) **Scout + Analyst** ← 권장
- B) Analyst만 (요구사항 원안 유지)
- C) 전 역할

> **권장 근거**: 유사작은 해외 영화제·마켓에서 스카우트가 가장 먼저 접합니다.
> "이거 작년 그 작품이랑 비슷하다"는 판단이 발굴 단계에서 나오는데, 그때 못 적으면
> 사라집니다. 유사작은 전부 공개 정보라 열어도 노출 위험이 없습니다.

[Answer]: A (권장안)

### Q-FD-4. 근거 탭의 **필터**를 어디까지 둘까요?

- A) **종류(kind) 필터만** ← 권장
- B) 종류 + 출처 등급 + 기간
- C) 필터 없이 전체 목록

> **권장 근거**: 작품 하나의 관측이 수십 건을 넘기 어렵습니다. 필터를 많이 만들면
> 화면이 무거워지고 쓰는 사람은 없습니다. 종류 필터만 두고, 실제로 부족하면 그때
> 늘리는 편이 낫습니다.

[Answer]: A (권장안)

## 5. 질문하지 않고 결정한 것 (검토용)

아래는 답이 비교적 자명하다고 판단해 결정했습니다. **동의하지 않으시면 말씀해 주세요.**

| # | 결정 | 근거 |
|---|---|---|
| D-1 | `observedAt` 미래 날짜는 **전 종류** 거부 | 미래를 관측할 수는 없습니다. FR-030은 트레일러만 규정했지만 나머지에 허용할 이유가 없습니다 |
| D-2 | `sourceName`은 REVIEW·BUYER_INTEREST·MARKET_NOTE에서 **필수** | 이 셋은 "누가 말했나"가 곧 신호입니다. 출처 없는 평판은 소문입니다 |
| D-3 | `metricValue`는 **정수(Int)**, BigInt 아님 | 인수 후보작 트레일러가 21억 회를 넘을 일은 없습니다. 금액과 달리 BigInt가 필요 없습니다 |
| D-4 | **`Signal` vs `Comment` 경계**: Comment = 사람끼리의 대화(멘션·협업), Signal = **출처가 있는 외부 관측** | 경계를 안 정하면 둘 다 자유 텍스트라 아무 데나 쌓입니다 |
| D-5 | U6에서 **알림을 만들지 않음** | 관측 기록은 알릴 일이 아닙니다. 멘션이 필요하면 Comment를 씁니다 |
| D-6 | 철회된 관측은 **건수 집계에서 제외**, 목록에는 표시 | 무효인 것이 숫자를 부풀리면 안 되지만, 있었다는 사실은 남아야 합니다 |
| D-7 | 유사작 관객수 단위는 **명(정수)** | KOBIS 기준과 맞춥니다 |
